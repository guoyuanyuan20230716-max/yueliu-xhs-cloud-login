# 阅流云端登录修复

为 `xpzouying/xiaohongshu-mcp` 添加 `/login-console`，用于查看同一个云端浏览器的实时截图、点击、输入短信验证码，并在完整登录后保存 Cookies。

本仓库仅含代码，不含密钥、验证码、Cookies 或个人推荐内容。上游固定版本：`7797fd375aba02dcd33afe143f6bee13e5870859`。

## 部署与使用

使用 Dockerfile 部署；必须设置非空 `AUTH_TOKEN`，健康检查路径 `/health`。打开服务域名下的 `/login-console`，输入现有访问密钥并连接。点击画面中的输入框，使用“输入到云端”填写，再点击画面中的确认按钮。完成验证、进入小红书主页后，点击“检查并保存登录”。

页面只在内存中保存密钥，不放入 URL、localStorage 或仓库；控制接口要求 Bearer 密钥和会话 ID，拒绝跨站请求，返回 no-store。空密钥时控制接口关闭。只有小红书 HTTPS 页面可操作，不提供任意 URL 导航或脚本执行接口。一次仅启动一个登录浏览器；会话 10 分钟后自动关闭。会话期间旧采集接口暂停，避免同时启动多个浏览器。

`/api/v1/login-console/start` 异步启动浏览器；`state` 查看状态，`frame` 获取画面，`action` 点击/输入/按键/滚动，`save` 验证并保存，`close` 关闭。输入内容不写入日志。不要在代码中填写任何真实密钥或验证码。

## 限制

免费 Render 实例会休眠且没有持久磁盘；重启会丢失 Cookies。本修复解决可视化登录缺口，不承诺免费实例的性能、平台风控或长期同步。没有自动完成验证码、滑块或其他平台安全校验；由账号所有者通过页面操作。

## 验证

Docker 构建时运行 `go test . -run '^TestConsole' -count=1`，检查鉴权、跨站请求、过期会话标识和域名限制，再编译服务。实际短信验证必须在云端部署后由账号所有者确认。

上游项目代码与浏览器组件的许可按上游仓库保留。
